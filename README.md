# Wave Function Collapse

This project is an implementation of Wave Function Collapse algorithm following this [guide](https://vectrx.substack.com/p/wave-function-collapse).

The main objective is to generate Super Mario Bros level with a single base input image.
There is also a base procedurale generation algorithm with a RNG (coded from [Infine Mario Bros](https://github.com/cflewis/Infinite-Mario-Bros/blob/master/src/main/java/com/mojang/mario/level/LevelGenerator.java))
